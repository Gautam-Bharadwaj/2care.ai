## Caveats (NOT covered by this script)

- **STT (Deepgram) accuracy.** Manual test required: speak the test
  utterance per language into the browser at `http://localhost:5174/`
  and confirm the transcript that lands at `/voice/chat`.
- **TTS (Cartesia / browser SpeechSynthesis) quality.** Ear-check
  pronunciation per language. **Kannada and Gujarati Cartesia voices
  are placeholder IDs in `agent/language.py`** — replace from
  <https://play.cartesia.ai/> before the demo. Browser
  SpeechSynthesis voices ship per-OS — Chrome on macOS has Indic
  voices preinstalled; some Linux distros do not.
- **Tool calls.** `/voice/chat` is text-only LLM; the production
  voice agent (LiveKit + tools) has these but isn't exercised here.
- **Language lock after 2 turns.** Hermetically tested in
  `tests/test_multilingual.py::test_scenario_7_language_switch_locks_after_two_turns`.
